# Exploration Tours (Whittaker)

Tours provide a **metaphor** for exploration strategy. Pick one per session.

| Tour               | Strategy                                                  | Good for                     |
|--------------------|-----------------------------------------------------------|------------------------------|
| **FedEx Tour**     | Follow a piece of data from input to final destination    | Data integrity, sync bugs    |
| **Saboteur Tour**  | Try to break things: bad data, kill processes, cut network| Robustness, error handling   |
| **Antisocial Tour**| Do everything the app does NOT want you to do             | Input validation, edge cases |
| **Couch Potato**   | Accept every default, never customize                     | Default config bugs          |
| **Landmark Tour**  | Visit every major screen/feature systematically           | Coverage gaps, navigation    |
| **Collector Tour** | Collect every output: every message, PDF, log entry       | Output correctness           |
