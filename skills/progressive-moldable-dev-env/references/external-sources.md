## Primary Sources

### Moldable Development Patterns

Oscar Nierstrasz and Tudor Girba
EuroPLoP 2024

Paper: [Moldable Development Patterns (arXiv:2409.18811)](https://scg.unibe.ch/assets/archive/papers/Nier24a-MoldableDevelopmentPatterns.pdf)

Defines the canonical pattern language: 15 patterns in three categories (Tooling, Modeling, Process). The authoritative source for patterns referenced throughout this skill.

## Glamorous Toolkit

The only complete implementation of moldable development (the "Moldable IDE" output mode).

- Website: [gtoolkit.com](https://gtoolkit.com/)
- Platform: Pharo Smalltalk
- Key feature: unified "image" model where the IDE and the running system share the same runtime
